# Sri-Ram-Rajya-Foundation-Website
A responsive WordPress organization website developed using Elementor and Astra with custom pages, enquiry forms, SEO setup, and plugin integration.
## Technologies Used

- WordPress
- Elementor
- Astra Theme
- HTML
- CSS
- JavaScript
- WordPress Plugins

## Key Features

- Responsive organization website
- Custom Elementor pages
- Contact and enquiry forms
- Header and footer customization
- Mobile and tablet optimization
- Basic SEO configuration
- Plugin integration
- Website maintenance and updates
